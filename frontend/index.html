    FAQ — GPX and merge

    What is a GPX file?

    GPX (GPS Exchange Format) stores a track: latitude, longitude, elevation, and time. It is the standard format for exchanging an activity between watches, bike computers, and platforms.

    How do I merge GPX files?

    Add several .gpx files, then start Merge. The GPX merge tool concatenates track points and orders them by timestamp in a single file.

    What does merge mean for GPX files?

    Merge means combining several activities into one. GPX MERGE produces a single activity from multiple files without mixing chronological order.

    Are points without a timestamp kept?

    No. For a reliable merge, points without a <time> tag are ignored. The final GPX file only contains dated points.
